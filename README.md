# ml-from-scratch

🧪 ML Learning Lab

A 10-week learning journey from machine-learning foundations to production ML and RAG systems.

This repository documents my notes, implementations, experiments, tests, projects, and reflections as I prepare for ML and ML-engineering roles.

🎯 Goals

* Strengthen my ML, mathematics, Python, and SQL foundations
* Implement core algorithms from scratch
* Build and test production-oriented ML systems
* Study deep learning, Transformers, and RAG
* Prepare for technical interviews
* Develop a focused project portfolio

🗺️ Roadmap

Week	Technical focus	Project milestone
1	Linear algebra, ML fundamentals, NumPy, Git/Linux	P1: Linear regression from scratch
2	PCA, SVD, regularization, statistics, SQL	P1 complete: Regression and PCA
3	Calculus, optimization, and classification	P2: Classification models
4	Probability, evaluation, FastAPI, Docker	P2 complete: Benchmark and API
5	Statistical inference, CV, ensembles, boosting	P3: Production ML experiments
6	XGBoost, testing, CI/CD, MLflow	P3 complete: Production ML system
7	Neural networks, backpropagation, PyTorch	P4: MLP/CNN/LSTM benchmark
8	Attention, embeddings, Transformers	P4 complete: Transformer NLP benchmark
9	LLMs, vector search, reranking	P5: Retrieval and evaluation system
10	RAG, tool calling, deployment, observability	P5 complete: Production RAG application

Alongside the technical work, I am gradually increasing targeted applications, networking, referrals, and interview preparation. After Week 10, I will improve P3–P5 based on feedback instead of continuously starting new projects.
