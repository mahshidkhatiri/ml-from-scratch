# ML Learning Lab

A structured 10-week learning repository covering machine-learning foundations, practical implementation, ML engineering, deep learning, and RAG systems.

This repository contains my notebooks, code, tests, experiments, and technical notes as I prepare for ML and ML-engineering roles.

**Status:** In progress

## Roadmap

| Week | Focus | Project milestone |
|---:|---|---|
| 1 | Linear algebra, NumPy, Git/Linux | Linear regression from scratch |
| 2 | PCA, SVD, regularization, statistics, SQL | Regression and PCA project |
| 3 | Calculus, optimization, classification | Classification models |
| 4 | Probability, evaluation, FastAPI, Docker | Classification benchmark and API |
| 5 | Statistical inference, cross-validation, ensembles | Production ML experiments |
| 6 | XGBoost, testing, CI/CD, MLflow | Production ML system |
| 7 | Neural networks, backpropagation, PyTorch | MLP/CNN/LSTM benchmark |
| 8 | Attention, embeddings, Transformers | Transformer NLP benchmark |
| 9 | LLMs, vector search, reranking | Retrieval and evaluation system |
| 10 | RAG, tool calling, deployment, observability | Production RAG application |
